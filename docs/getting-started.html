Getting started

Use this flow for your first run, then move to API or script workflows.

Quick map: Quick reference Repository workflow Examples Verify results

Quick reference (3-minute setup)

# 1) editable install
python -m pip install -e .

# 2) check CLI
python -m simpledet --version
python -m simpledet --check-openmmlab

# 3) CUDA sanity
python -c "import torch; print('torch', torch.__version__, 'cuda', torch.cuda.is_available())"

Core public surface in Python:

from simpledet import train, detect, evaluate, Config, detectors

Repository quick use map

1. Install & check

Use CLI diagnostics first, then choose your execution style.

2. Train

Use script launchers or API training with train(config={...}).

3. Infer

Use load_model + predict for reusable inference.

4. Evaluate

Use simpledet.evaluate or pipeline-aware flow.

Examples (copyable snippets)

A) API training (minimal)

from simpledet import train

result = train(
    config={
        "dataset": "path/to/coco_or_root",
        "output_dir": "results/mmdet_smoke",
        "model_name": "faster_rcnn_resnet50_fpn",
        "epochs": 1,
        "batch_size": 2,
        "learning_rate": 0.001,
        "train_split": "train",
        "num_workers": 4,
        "device": "cuda",
    }
)

print(result["checkpoint_path"])
print(result["metrics_path"])

B) Build and run inference with a checkpoint

from PIL import Image
from simpledet.detectors.infer import load_model, predict

model = load_model(
    checkpoint="results/mmdet_smoke/epoch_001.pth",
    device="cpu",
    score_threshold=0.2,
    max_detections=128,
)

result = predict(Image.open("path/to/sample.tif"), model=model)
print(result["boxes"][:3])
print(result["scores"][:3])
print(result["class_ids"][:3])

C) Dataset format checks

from simpledet.detectors.data import list_formats, load_dataset

print(list_formats())
payload = load_dataset(path="path/to/dataset_root", format="coco")
print(payload.keys())
print(f"images: {len(payload.get('images', []))}")

D) Evaluate with an existing pipeline (legacy flow)

from simpledet.api import ObjectDetectionPipeline
from simpledet import evaluate

pipeline = ObjectDetectionPipeline(
    model_cfg={},
    batch_size=2,
    max_epochs=1,
    data_folder="/path/to/data",
    annot_file_train="/path/to/train_annotations.json",
    annot_file_val="/path/to/val_annotations.json",
    annot_file_test="/path/to/test_annotations.json",
    config_folder="./MyConfigs",
    tif_channels_to_load=[1],
    categories=("wake",),
)

result = evaluate(pipeline=pipeline)
print("evaluate completed", result)
