Fast path

  1. Install the package and OpenMMLab runtime.
  2. Build a detector with simpledet.suite.build_detector(...).
  3. Run ObjectDetectionPipeline(detector_spec=...) for training and evaluation.
  4. Use the notebooks in notebooks/Tools/ for guided examples.
