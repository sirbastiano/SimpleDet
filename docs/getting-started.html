Running / Getting started

Use these commands to validate your environment, launch a smoke run, and run basic inference.

Quick map: Prerequisites Sanity checks Training smoke test Inference Verify outputs

Prerequisites

Install first, then run CLI validation:

python -m pip install -e .
python -m simpledet --version
python -m simpledet --check-openmmlab

Quick sanity checks

python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python - <<'PY'
from pathlib import Path
print('annotations exists:', Path('path/to/annotations.json').is_file())
print('images exists:', Path('path/to/images').is_dir())
PY

Training smoke test

Run a 1 epoch command first, then scale settings for production.

python runscripts/SenTrainer.py \
  --batch_size 2 \
  --band "[5]" \
  --seed 71 \
  --learning_rate 0.001 \
  --max_epochs 1 \
  --sensor SENTINEL \
  --AMP False

Run a VENUS variant smoke test:

python runscripts/VenTrainer.py \
  --batch_size 2 \
  --band "[10]" \
  --seed 54 \
  --learning_rate 0.0009 \
  --max_epochs 1 \
  --sensor VENUS

API usage

from simpledet import train

result = train(config={
    "dataset": "path/to/annotations.json",
    "output_dir": "runs/mmdet_smoke",
    "model_name": "faster_rcnn_resnet50_fpn",
    "epochs": 1,
    "batch_size": 2,
    "learning_rate": 0.001,
    "dataset_path": "path/to/dataset_root",
    "train_split": "train",
    "device": "cuda",
})
print(result["checkpoint_path"])

Inference

from PIL import Image
from simpledet.detectors.infer import load_model, predict

model = load_model(
    "runs/mmdet_smoke/epoch_001.pth",
    device="cpu",
    score_threshold=0.2,
    max_detections=200,
)

res = predict(Image.open("path/to/sample.tif"), model=model)
print(res["boxes"][:5], res["scores"][:5], res["class_ids"][:5])

Verify training output

ls -R runs/mmdet_smoke

python - <<'PY'
import json
with open("runs/mmdet_smoke/coco_metrics.json") as f:
    m = json.load(f)
print(m.keys())
PY

Minimum expected files from the smoke run:

ls runs/mmdet_smoke/*.pth
