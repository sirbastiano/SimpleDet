Current public surface

  • simpledet --version and python -m simpledet --check-openmmlab for diagnostics.
  • simpledet.suite for DetectorSpec, builders, and compilation.
  • simpledet.api.ObjectDetectionPipeline for training, testing, and evaluation.
  • simpledet.detectors.* for lightweight training, inference, and generic dataset loading.
