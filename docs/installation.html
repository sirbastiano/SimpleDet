Installation

Install the package, verify entrypoints, and validate optional OpenMMLab tooling.

Quick map: Requirements Install Verification Advanced

Requirements

  • Python 3.8+
  • torch + mmengine + mmdet for API operations
  • CUDA/driver alignment if using GPU training
python --version
python -m pip --version

Editable install (recommended)

git clone https://github.com/sirbastiano/MDet.git
cd MMDET
python -m pip install -e .

Install with OpenMMLab extras

If you need optional runtime tooling:

python -m pip install -e .[openmmlab]

Verify CLI entrypoint

python -m simpledet --version
simpledet --help

Runtime validation

python -m simpledet --check-openmmlab

Check fails when torch, numpy, torchvision, mmengine, or mmdet is missing.

Script-first / environment helpers

Repo helper scripts:

./setup.sh
./deploy.sh

Use these only if your environment matches the script assumptions.
