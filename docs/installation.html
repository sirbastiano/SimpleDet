Installation

Install the package from source, add the OpenMMLab runtime, then verify the suite and pipeline entry points.

Use this page first if commands from the other docs are failing and you are not yet sure the environment is valid.

Requirements

  • Python >=3.8
  • PyTorch runtime compatible with your CPU or CUDA environment
  • mmengine, mmdet, and mmcv==2.1.0 for the pipeline path
  • timm if you want suite-driven backbone swapping

Install from source

git clone https://github.com/sirbastiano/SimpleDet.git
cd SimpleDet
python -m pip install -e .
python -m pip install ".[openmmlab]"

The optional extra currently includes openmim, mmcv==2.1.0, timm, and plotting or data utilities used by the repository.

Verify the runtime

python -m simpledet --version
python -m simpledet --check-openmmlab
python - <<'PY'
from simpledet.detectors.data import list_formats
from simpledet.suite import build_detector, compile_detector_spec

print(list_formats())
spec = build_detector("retinanet", encoder="resnet18.a1_in1k", num_classes=2, in_channels=3)
print(compile_detector_spec(spec)["backbone"]["type"])
PY

Expected output shape:

0.1.0
Optional OpenMMLab runtime stack is available.
['coco', 'csv', 'json', 'voc', 'yolo', ...]
TimmEncoder

Notes

  • The lightweight torchvision helpers can run without the full OpenMMLab stack.
  • The suite plus pipeline workflow depends on the OpenMMLab runtime.
  • device="auto" in the lightweight inference helper currently resolves to CPU.

If python -m simpledet --check-openmmlab fails, fix the environment before debugging pipeline code.
