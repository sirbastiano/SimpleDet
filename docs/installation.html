Installation

Install for development, run a fast runtime check, then validate optional OpenMMLab dependencies.

Quick map: Requirements Install Verification Troubleshooting

Requirements

Python 3.10+ is recommended. You need a working CUDA-enabled setup only if you plan to train on GPU.

python --version
python -m pip --version

Editable install

Clone the repository and install the package in editable mode from project root:

python -m pip install -e .

Alternative package check:

python -m simpledet --version

From a new terminal, verify CLI launch works:

simpledet --help

OpenMMLab dependency check

python -m simpledet --check-openmmlab

If your environment is using CUDA, keep torch/cuda versions aligned with your GPU driver.

Troubleshooting

  • CLI not found: ensure install succeeded and check active environment/bin path.
  • Version mismatch: rerun your CUDA/torch install and then reinstall dependencies.
  • Permission issues: avoid global installs; use virtual environments only.
