Core concepts

Understand runtime execution before changing training scripts or configs.

Quick map: Architecture Public entry points Data model Artifacts

Architecture overview

  • simpledet.cli – thin entrypoint for version and OpenMMLab checks.
  • simpledet.api.ObjectDetectionPipeline – legacy OpenMMLab pipeline entry.
  • simpledet.detectors – lightweight public API for train/infer/evaluate.
  • simpledet.detectors.data – dataset format adapters and loading.
  • runscripts/ – script wrappers for preset training/inference flows.

Public entry points

CLI (`simpledet` / `python -m simpledet`)

python -m simpledet --version
python -m simpledet --check-openmmlab
simpledet --help

simpledet is wired through [project.scripts] in pyproject.toml; fallback is always python -m simpledet.

Python API

from simpledet import train, detect, evaluate
train(config={...})
detect(pipeline=...)
evaluate(pipeline=...)

Inference utilities

from simpledet.detectors.infer import load_model, predict

model = load_model(checkpoint="path/to/checkpoint.pth", device="cpu")
res = predict("image.tif", model=model)

Data model

  • API training config uses: dataset/model_name/output_dir/epochs/batch_size/learning_rate.
  • Dataset detection supports explicit and auto format selection.
  • Model names are validated before training.

Artifacts and outputs

  • epoch_###.pth: checkpoint file.
  • metrics.json: training metrics and run summary for public API mode.
  • Legacy pipeline mode writes tests.pkl and metrics.pkl in the configured work directory.

import json
