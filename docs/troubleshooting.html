Troubleshooting

Issue-to-fix matrix for install, CLI, data, scripts, and API execution.

Issue Likely cause How to resolve
python -m simpledet --check-openmmlab returns missing dependency Optional dependencies for runtime checks are not installed Install required modules and retry: python -m pip install -e .[openmmlab], then rerun the check.
simpledet --help not found CLI entrypoint not installed in current environment Reactivate the environment and run python -m pip install -e . from repo root, then rerun python -m simpledet --version.
Script run exits with KeyError/Model not configured Legacy launcher expects expected data and annotation paths Double-check data_folder, annot_file_train, annot_file_val, annot_file_test.
API training returns empty dataset / no samples Wrong dataset path or unsupported format Run from simpledet.detectors.data import list_formats, load_dataset; pass explicit format='coco'/json/yolo.
Checkpoint inference fails: unsupported format Checkpoint extension must be .pth/.pt/.ckpt Use supported extension or call load_model(checkpoint=...) with a valid file path.
CUDA not used even if available Config or launch command forces CPU For API mode set device='cuda' and verify torch.cuda.is_available().
Legacy pipeline fails during construction OpenMMLab runtime path is stricter than API mode Confirm all optional dependencies with python -m simpledet --check-openmmlab, then validate arguments before ObjectDetectionPipeline(...).
`simpledet` commands time out on import Heavy environment import from optional modules Use script entrypoint only for checks; load modules lazily during model runs.
