Examples

Three practical detector patterns that match the current suite plus pipeline API.

Satellite imagery vessel detection

from simpledet.suite import build_detector, build_neck

detector_spec = build_detector(
    "vfnet",
    encoder="convnext_tiny.in12k_ft_in1k",
    neck=build_neck(name="FPN", out_channels=192, num_outs=5),
    num_classes=1,
    in_channels=4,
)

Notebook starting point: notebooks/Tools/suite_01_dense_detector.ipynb.

Building detection

from simpledet.suite import build_detector, build_neck

detector_spec = build_detector(
    "mask_rcnn",
    encoder="swin_tiny_patch4_window7_224.ms_in22k_ft_in1k",
    neck=build_neck(name="FPN", out_channels=192),
    num_classes=1,
    in_channels=3,
)

Notebook starting point: notebooks/Tools/suite_02_roi_detector.ipynb.

Ship detection with a transformer detector

from simpledet.suite import build_decoder, build_detector, build_neck

detector_spec = build_detector(
    "deformable_detr",
    encoder="convnext_tiny.in12k_ft_in1k",
    neck=build_neck(name="ChannelMapper", out_channels=192, num_outs=4),
    decoder=build_decoder(embed_dims=192, num_queries=300),
    num_classes=1,
    in_channels=3,
)

Notebook starting point: notebooks/Tools/suite_03_transformer_detector.ipynb.
