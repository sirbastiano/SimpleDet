Training

Use the suite plus pipeline path for real experiments. The lightweight path is still available for quick local smoke tests.

Recommended training path

from simpledet.api import ObjectDetectionPipeline
from simpledet.suite import build_detector, build_neck

detector_spec = build_detector(
    "vfnet",
    encoder="convnext_tiny.in12k_ft_in1k",
    neck=build_neck(name="FPN", out_channels=192, num_outs=5),
    num_classes=3,
    in_channels=3,
)

pipeline = ObjectDetectionPipeline(
    detector_spec=detector_spec,
    data_folder="/data/project",
    result_folder="results/project",
    config_folder="simpledet/simpledet/src",
    data_prefix="imgs/",
    annot_file_train="/data/project/annotations/train.json",
    annot_file_val="/data/project/annotations/val.json",
    annot_file_test="/data/project/annotations/test.json",
    tif_channels_to_load=[1, 1, 1],
    in_channels=3,
    categories=("car", "building", "ship"),
    resize=768,
    batch_size=2,
    learning_rate=0.001,
    max_epochs=30,
)

pipeline.build()
pipeline.train()

What the pipeline injects

  • dataset roots and annotation paths
  • resize and dataloader settings
  • optimizer and schedule choices
  • workdir, logging, and evaluator wiring
