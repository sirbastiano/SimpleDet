Quickstart

This tutorial is the shortest path through the current repository. It explains not only what to run, but why the repo is split into a detector-definition step and a pipeline-execution step.

1. Install and verify

The suite and pipeline path depend on the OpenMMLab runtime. Verify the environment first so you do not debug docs examples with a broken install. 

python -m pip install -e .
python -m pip install ".[openmmlab]"
python -m simpledet --check-openmmlab

2. Build a detector

A DetectorSpec is the repo’s high-level model description. It says which detector family you want, which backbone it should use, and how many classes it must predict. The compiler then turns that high-level description into an MMDetection-style model dictionary. 

python - <<'PY'
from pprint import pprint
from simpledet.suite import build_detector, compile_detector_spec

spec = build_detector(
    "retinanet",
    encoder="resnet18.a1_in1k",
    num_classes=2,
    in_channels=3,
)
model_cfg = compile_detector_spec(spec)

print(spec.family)
pprint(model_cfg["backbone"])
pprint(model_cfg["neck"])
pprint(model_cfg["bbox_head"])
PY

Expected output shape:

dense
{'type': 'TimmEncoder', ...}
{'type': 'FPN', ...}
{'type': 'RetinaHead', 'num_classes': 2, ...}

The key concept is that you are not writing the full model dictionary by hand. SimpleDet inspects the backbone, infers feature channels, and patches the neck and head interfaces for you.

3. Train through the pipeline

The pipeline owns everything that is not intrinsic to the detector itself: dataset locations, annotation files, image resize, logging, checkpointing, and evaluator outputs. 

from simpledet.api import ObjectDetectionPipeline
from simpledet.suite import build_detector

detector_spec = build_detector(
    "retinanet",
    encoder="resnet18.a1_in1k",
    num_classes=2,
    in_channels=3,
)

pipeline = ObjectDetectionPipeline(
    detector_spec=detector_spec,
    data_folder="/path/to/dataset_root",
    result_folder="/path/to/results",
    config_folder="simpledet/simpledet/src",
    data_prefix="imgs/",
    annot_file_train="/path/to/annotations/train.json",
    annot_file_val="/path/to/annotations/val.json",
    annot_file_test="/path/to/annotations/test.json",
    tif_channels_to_load=[1, 1, 1],
    in_channels=3,
    categories=("object_a", "object_b"),
    resize=768,
    batch_size=2,
    learning_rate=0.001,
    max_epochs=10,
)

pipeline.build()
pipeline.train()

build() prepares the runtime configuration and runner. train() launches the actual experiment. The detector spec becomes cfg.model, while the shared runtime config still controls dataloaders, hooks, and evaluation setup.

4. Evaluate

Evaluation is not a standalone subsystem in this repo. It reuses the pipeline test path so the evaluator, output files, and dataset metadata remain consistent with training. 

from simpledet import evaluate

metrics = evaluate(pipeline=pipeline, build=False)
print(type(metrics).__name__)

Expected artifacts:

  • pipeline.log
  • best_*.pth
  • tests.pkl
  • metrics.pkl
  • testSet* evaluator outputs

What to remember

DetectorSpec

Describes the detector architecture you want to run.

Compiled model config

Is the low-level MMDetection model dictionary generated from that high-level spec.

Pipeline

Attaches runtime concerns such as datasets, workdir layout, hooks, and evaluators.
