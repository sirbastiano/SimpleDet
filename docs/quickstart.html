Quickstart

Build a detector with the suite API, inspect the compiled model, then launch training and evaluation through the pipeline.

1. Install and verify

python -m pip install -e .
python -m pip install ".[openmmlab]"
python -m simpledet --check-openmmlab

2. Build a detector

python - <<'PY'
from pprint import pprint
from simpledet.suite import build_detector, compile_detector_spec

spec = build_detector(
    "retinanet",
    encoder="resnet18.a1_in1k",
    num_classes=2,
    in_channels=3,
)
model_cfg = compile_detector_spec(spec)

print(spec.family)
pprint(model_cfg["backbone"])
pprint(model_cfg["neck"])
pprint(model_cfg["bbox_head"])
PY

Expected output shape:

dense
{'type': 'TimmEncoder', ...}
{'type': 'FPN', ...}
{'type': 'RetinaHead', 'num_classes': 2, ...}

3. Train through the pipeline

from simpledet.api import ObjectDetectionPipeline
from simpledet.suite import build_detector

detector_spec = build_detector(
    "retinanet",
    encoder="resnet18.a1_in1k",
    num_classes=2,
    in_channels=3,
)

pipeline = ObjectDetectionPipeline(
    detector_spec=detector_spec,
    data_folder="/path/to/dataset_root",
    result_folder="/path/to/results",
    config_folder="simpledet/simpledet/src",
    data_prefix="imgs/",
    annot_file_train="/path/to/annotations/train.json",
    annot_file_val="/path/to/annotations/val.json",
    annot_file_test="/path/to/annotations/test.json",
    tif_channels_to_load=[1, 1, 1],
    in_channels=3,
    categories=("object_a", "object_b"),
    resize=768,
    batch_size=2,
    learning_rate=0.001,
    max_epochs=10,
)

pipeline.build()
pipeline.train()

4. Evaluate

from simpledet import evaluate

metrics = evaluate(pipeline=pipeline, build=False)
print(type(metrics).__name__)

Expected artifacts:

  • pipeline.log
  • best_*.pth
  • tests.pkl
  • metrics.pkl
  • testSet* evaluator outputs
